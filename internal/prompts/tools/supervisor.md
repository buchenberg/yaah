Supervise running sub-agents, selected by `action`. `list_scopes` shows every scope and its state; `status` reports the supervision system status.

`inject` records `guidance` in the trace and delivers it to the scope named by `scope_id`. Delivery is best-effort: if the scope has no active run, or the supervision bridge is not active, the guidance is trace-only; if the run's steering buffer is full it is recorded but not consumed, so consider halting or retrying later. Injecting into the session root steers the session itself.

`halt` asks the scope to stop: it cancels a running loop, waits up to 10 seconds for it to quiesce, then records the kernel halt. A halt is not an instant stop. It reports whether the run stopped after cancellation, was cancelled but had not stopped within the bound (an in-flight tool may be interrupted by sandbox teardown), or had no active run to cancel (or the bridge was inactive) and was recorded in the trace only. Halting the session root requires `agents.default.supervisor_halt_root`; without that opt-in it is refused because it stops the session's current run and ends scope-tree supervision for the process. Halt a sub-agent scope when you only need to stop one dispatch.
