Runs guided `git bisect` to find which commit introduced a bug. `action: "start"` with `good_ref` and `bad_ref` begins the search; passing `test_cmd` makes it auto-bisect by running that command at each step (exit 0 = good, non-zero = bad). `action: "good"`, `"bad"`, or `"skip"` with `ref` guides the search manually — `test_cmd` is not accepted there; run the test yourself and mark the result. `log` shows progress and `reset` aborts and restores the original HEAD.
