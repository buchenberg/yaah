Fetches content from `url` and returns the response body. `format` selects the rendering: `html` returns the raw body; `text` strips HTML tags and decodes entities into plain text; `markdown` — the default — is currently the same text extraction as `text`, applied when the response is HTML. Links, tables, and document structure are not preserved. Non-HTML bodies are returned verbatim. Output is truncated at a size cap. HTTP error statuses fail and include the response body so a 403 or 404 explains itself. Use to retrieve web pages, API responses, or documentation.
