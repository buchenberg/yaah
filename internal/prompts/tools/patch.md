`patch(patch, filePath?)` — Applies an inline unified diff to a single file. The patch argument must be unified diff text containing one or more `@@` hunks; it is not a path to a `.patch` file. Multi-file diffs are rejected — apply each file separately. A patch is all-or-nothing: if any hunk fails, the target is left unchanged and the failure is an error. Use `edit` for exact string swaps; use `replace` for regex replacements.

Writes to the same file are serialized in-process, so a same-file pair in one batch is ordered rather than lost, and a target that changed since the call read it is refused with both digests (`file changed by another writer ...; re-read and retry`) and left untouched. A successful patch keeps its line counts and ends with a receipt line — the path, the byte delta, and the digest of the patched file; the two must agree.
