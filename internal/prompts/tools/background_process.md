Manages long-running background processes. `action: "start"` launches a command with a description; `action: "list"` shows every tracked process with its current status, including ones that have already exited; `action: "status"` checks a specific process by its `id`; `action: "logs"` retrieves output; `action: "stop"` terminates; `action: "restart"` stops and restarts. Use for servers, watchers, builds, and other long-running tasks that should run while you continue working.

`start` and `restart` execute an arbitrary shell command, so they are approval-gated exactly like `bash`; their command is also checked against the same best-effort dangerous-pattern deny-list, which refuses the most blatant destructive commands even when approval is set to `allow`. `list`, `status`, `logs`, and `stop` do not execute a new command and are not gated. A restart re-runs the stored command, so it takes a fresh approval decision and is refused (without stopping the running process) if that command matches the deny-list.
