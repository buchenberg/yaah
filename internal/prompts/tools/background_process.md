Manages long-running background processes. `action: "start"` launches a command with a description; `action: "list"` shows all running processes; `action: "status"` checks a specific process by ID; `action: "logs"` retrieves output; `action: "stop"` terminates; `action: "restart"` stops and restarts. Use for servers, watchers, builds, and other long-running tasks that should run while you continue working.
