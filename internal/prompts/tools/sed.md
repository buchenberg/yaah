Regex find-and-replace across files with multi-file glob patterns and dry-run mode. Uses Go regex syntax. Specify `pattern` to match, `replacement` (with `$1`, `$2` for capture groups), `path` (file or directory; directories are walked recursively), `include` as a glob pattern to filter files (defaults to `*.go` for directories), and `dryRun: true` to preview changes without writing. Destructive by default — use dry-run first.
