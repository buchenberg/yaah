Searches persistent memory notes (user facts, preferences, project details, decisions) by meaning — semantic vector search that understands paraphrases and conceptual similarity, not just keyword matching (falls back to full-text if no embedding server is available). Returns matching entries with IDs, text, tags, tier, and age. Use before answering personal or project-specific questions.

Every entry lives in one of two tiers. A `global` fact outlives any single session; a `session` atom was distilled from one conversation — including conversations that ended days ago. A search defaults to `global` only, because session atoms are one conversation's working context. Pass `scope` to widen it: `"session"` reaches atoms distilled from earlier conversations, `"all"` spans both. If someone asks what was decided or learned previously and the default search comes up empty, widening the scope is almost always the right next move rather than concluding nothing is known.

Optional arguments: `tag` filters by category (e.g., `"user_info"`, `"preferences"`, `"project:yaah"`, `"decision"`), `top_k` limits results (default 10), and an empty `query` lists the most recent entries instead of searching. Recall is recorded — entries that are read back are the ones that survive pruning, so prefer searching over guessing.
