Searches stored memory notes (user facts, preferences, project details, decisions). Returns matching entries with IDs, text, and tags. Use `query` for full-text search (empty to list all), `tag` to filter by category (e.g., `"user_info"`, `"preferences"`, `"project:yaah"`, `"decision"`), and `top_k` to limit results (default 10). Use before answering personal or project-specific questions.
