Writes the structured todo list for the current session. Each entry in `todos` has `content` (description), `status` (pending, in_progress, completed, cancelled), and optional `priority` (high, medium, low). Todos have no identity: the array you send replaces the entire list, so include every item you want to keep and match old items to new by content. The response reports counts only (total, completed, in progress, pending), never the items themselves. Use for tracking progress through multi-step tasks during a session.
