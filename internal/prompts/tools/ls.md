Lists directory contents with optional depth control. Shows files and subdirectories — names and tree layout only, no sizes or timestamps. Commonly ignored directories (.git, node_modules, vendor, build, and similar) are hidden, so a directory holding only ignored entries appears childless. Default depth is 1 (immediate children only); set `depth` up to 5 for a recursive listing. `path` defaults to the current working directory. Use to explore project structure, verify file locations, or survey a directory before targeted reads.
