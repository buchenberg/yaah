Run a git command (status, diff, log, show, branch, add, commit, push, pull, fetch). The `action` parameter selects the operation; `flags` accepts safe flags (`["--oneline", "-5", "--stat"]`); `paths` targets specific files or revisions; `message` is required for `commit`. Read-only actions (status, diff, log, show, branch) are safe; mutating actions (add, commit, push, pull, fetch) require approval unless approval gating is enabled.
