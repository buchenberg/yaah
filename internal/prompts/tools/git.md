Run a git command (status, diff, log, show, branch, add, commit, push, pull, fetch). The `action` parameter selects the operation; `flags` accepts ONLY dash-prefixed options like `["--oneline", "-5", "--stat"]` — never put branch names, file paths, or refs here; `paths` targets file paths, branch names (for branch), or revision refs (for show/log/diff); `message` is required for `commit`. Read-only actions (status, diff, log, show, branch) are safe; mutating actions (add, commit, push, pull, fetch) require approval unless approval gating is enabled.
