Spawns a sub-agent with a specific role and tool set to autonomously complete a subtask. Required params: `description` (3-5 word summary), `prompt` (the task), and `role` (analyst, developer, tester, reviewer, checker, counter, security_auditor). Optional: `background` (dispatch and return immediately), `json_mode` (structured JSON output), `max_iterations` (1-50), `max_turns` (1-50), `output_limit` (byte cap), `timeout_seconds` (10-600). Use for complex multi-step work — sub-agents can read, write, and execute tools independently.
