Searches past conversation sessions. With no query, lists recent sessions with their first prompt as a topic summary (newest first; sub-agent sessions marked `[SUB]`). Set `top_k: 1` to get only the most recent session. Provide a `query` for semantic vector search across session transcripts — understands paraphrases and conceptual similarity (falls back to full-text if no embedding server is available), and `top_k` to limit results (default 10). Use to find past discussions, recall previous work, or review conversation history across sessions.
