Searches past conversation sessions. With no query, lists recent sessions with their first prompt as a topic summary (newest first; sub-agent sessions marked `[SUB]`). Set `top_k: 1` to get only the most recent session. Provide a `query` for full-text search across session transcripts, and `top_k` to limit results (default 10). Use to find past discussions, recall previous work, or review conversation history across sessions.
