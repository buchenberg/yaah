Finds files matching a glob pattern. Returns sorted file paths. Uses ripgrep (`rg --files --glob`) when available for speed, otherwise falls back to a native Go walker. Supports standard glob syntax: `*` (any chars except path separator), `**` (recursive), `?` (single char), `{a,b}` (alternation), `[abc]` (character class). Use to locate files by pattern before reading or editing them.
