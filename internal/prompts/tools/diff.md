Runs `git diff` or unified `diff` and returns structured per-file statistics (insertions, deletions, files changed) plus the full unified diff. Compare `a` against `b` — file paths or git refs; an empty `b` compares against the working tree. `mode` switches between `git` diff and the system `unified` diff, `path` restricts the comparison to one file or directory, and `context_lines` sets how much unchanged context surrounds each change. Use for reviewing changes before commits, comparing branches, or inspecting file differences.
