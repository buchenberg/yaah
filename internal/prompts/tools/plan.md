Create, review, and manage plans stored as PLAN.md files in `.agents/plans/`. Plans have a status workflow: draft → approved → in_progress → completed → cancelled. `action: "create"` makes a new plan with a name, description, and body; `action: "list"` shows all plans; `action: "show"` displays details; `action: "approve"` promotes to approved; `action: "edit"` modifies; `action: "delete"` removes. Use before starting complex multi-step work. This tool manages PLAN.md files; it is not plan mode — plan mode is the session mode that narrows the toolset to the inspection set (and admits this tool), and only the user switches it.
