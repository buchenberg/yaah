Run a sub-agent with automatic rollback and retry on failure. BLOCKING — this call does not return until the sub-agent completes or all retries are exhausted. A git checkpoint of the workspace is taken before each attempt; if the sub-agent fails, its changes are rolled back and it is retried with guidance from the failure. Required params: `prompt` (the task) and `role` (sub-agent role; use list_subagents for details). Optional: `description` (short label), `timeout_seconds` (10-600 per attempt), `max_iterations` (1-50). Returns the sub-agent's output on success, or a JSON object with `status`, `attempts`, `error`, and `partial` on failure. Use when correctness matters more than throughput; do NOT use for parallel or background work — use spawn_subagent for that.
