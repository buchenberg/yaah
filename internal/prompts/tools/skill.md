Load, list, create, edit, delete (archive), or search skills. Skills are `SKILL.md` files with YAML frontmatter and markdown instructions stored in project (`.agents/skills/`) or global (`~/.agents/skills/`) directories. `action: "load"` injects a skill's instructions into the current context; `action: "list"` shows available skills; `action: "create"` and `action: "edit"` modify skill files, addressing the skill by `name` and taking the markdown instructions as `body`; `action: "delete"` archives a skill into a `.archive/` directory beside its skills root instead of destroying it, so it can be restored; `action: "search"` matches skills against a natural-language `query`. Use `load` when a task matches a skill's description.
