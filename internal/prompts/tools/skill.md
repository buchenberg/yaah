Load, list, create, or edit skills. Skills are `SKILL.md` files with YAML frontmatter and markdown instructions stored in project (`.agents/skills/`) or global (`~/.agents/skills/`) directories. `action: "load"` injects a skill's instructions into the current context; `action: "list"` shows available skills; `action: "create"` and `action: "edit"` modify skill files. Use `load` when a task matches a skill's description.
