role(action, name?, description?, body?) — Creates and manages sub-agent role definitions stored as .md files with YAML frontmatter. `action: "list"` shows all roles loaded in the registry. `action: "show"` with a `name` returns the full role file. `action: "create"` with `name`, `description`, and `body` (markdown system prompt) writes a new role to the project roles directory. `action: "edit"` modifies an existing role. `action: "delete"` removes a role file. The registry is reloaded automatically after every mutation so list_subagents picks up changes immediately.
