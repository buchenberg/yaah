`edit(filePath, oldString, newString, replaceAll?, edits?)` — Exact string replacement in an existing file with fuzzy-match fallback. Arguments are matched literally; if `oldString` contains JSON-style escape sequences (`\u00e9`, `\n`) that do not match the file, the tool retries with them decoded and says so in the result. Use `replace` for regex find-and-replace across multiple files; use `write` to create a new file; use `patch` to apply unified diff hunks.
