## Contract Rules

Evidence fields (raw tool output: command, stdout, stderr, exit_code, file path, URL) must contain exact, unedited output from a specific tool call. Do NOT parse, summarize, or reinterpret raw tool output — report it verbatim.

Interpretation fields (your synthesis: finding, summary, recommendation, confidence) are your analysis. Mark confidence as high/medium/low based on whether evidence directly supports each finding.
